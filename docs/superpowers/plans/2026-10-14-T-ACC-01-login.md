# T-ACC-01 Login, Sessions and CSRF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staff can log in with username and password, choose a hospital when they belong to several, stay logged in under the C-032 timeouts, and log out; every state-changing request is protected by a CSRF token and every tenant request runs inside the chosen hospital.

**Architecture:** A new module package `@hms/mod-identity-access` (D §5) owns the domain rules (session timing, account status), infrastructure (argon2id hashing, session tokens, CSRF HMAC, Prisma repositories) and the HTTP layer (controller, global guards, cookie). Shared Nest pieces (database provider, problem+json filter, Zod pipe, audit writer) go in `@hms/platform`. The browser calls the API origin directly with a host-only session cookie and an `X-CSRF-Token` header (ADR-021).

**Tech Stack:** NestJS 12.1.2, Prisma 7.10.0 + `@prisma/adapter-pg`, PostgreSQL 17, Zod 4.6.6, argon2 0.45.1, cookie-parser 1.4.7, Vitest 5.0.4 + unplugin-swc.

**Spec:** `docs/planning/docs/G-implementation-plan.md` (T-ACC-01 row), `docs/planning/docs/C-srs/C01-platform-access-audit.md` (UC-ACC-01, FR-ACC-001/002/005/009), `docs/planning/docs/H-automated-test-plan.md` (AT-ACC-001..005), ADR-003, ADR-004, ADR-021, A2 C-032.

## Global Constraints

- Node 24, TypeScript 6.0.3, ESM everywhere (`.js` suffix on relative imports).
- Exact version pins; pnpm `minimumReleaseAge` stays on (pick the previous release if one is under a day old).
- Session timeouts from C-032: idle **60 minutes**, absolute **12 hours**.
- Cookie (ADR-021): name `hms_session`, `HttpOnly`, `Secure`, `SameSite=Lax`, `Path=/`, **no `Domain` attribute**.
- CSRF header name: `X-CSRF-Token`. Required on every POST/PUT/PATCH/DELETE except `POST /api/v1/auth/login`.
- API base path `/api/v1`; `/health` stays at the root.
- Errors are RFC 9457 `application/problem+json` with a stable `code` from `@hms/contracts`.
- All tenant data goes through `withTenant()`; the app connects as `hms_app` only.
- Code rules from CLAUDE.md: plain ASCII punctuation, a header comment on every feature file, comments explain why, no dead code.
- Tables live in schema `hms`; IDs are UUIDv7 from Prisma (`@default(uuid(7))`).

## Decisions for review (flagged before coding)

1. **Pre-tenant auth events get their own table, `auth_event`.** `audit_event` is tenant-scoped with RLS (`tenant_id NOT NULL`), but a failed login has no tenant. `auth_event` (user-level, append-only, no tenant) records login success/failure/logout; `audit_event` additionally gets `auth.login.succeeded` / `auth.logout` once a hospital is bound, so each hospital's audit trail shows its own logins.
2. **CSRF token = HMAC-SHA256(`CSRF_SECRET`, session token)** instead of the E design's stored `csrf_token_hash` column. Same protection, no extra column, and the token can be re-issued after a page reload (`GET /api/v1/auth/session`).
3. **`audit_event` is not partitioned yet.** E designs monthly partitions; partitioning belongs with retention (Q-053, T-PLT-02). Prisma does not model partitioned tables, so starting unpartitioned avoids drift; converting later is a planned migration.

## Review Focus

1. **Username with different case or spaces** ("Admin " vs "admin"): must find the same account. Pinned in Task 6 (`logs in regardless of username case and spaces`).
2. **Cookie reused after logout or after hospital switch**: must get 401. Pinned in Task 6 (`old token is rejected after selectMembership` and `logout revokes the session`).
3. **A busy user never idles out but passes 12 hours**: sliding idle expiry must never extend past the absolute limit. Pinned in Task 4 (`never slides past the absolute expiry`) and Task 6 (`absolute expiry ends an active session`).
4. **Very long or empty password**: rejected with 422 before hashing, so argon2 cannot be used to exhaust CPU. Pinned in Task 1 (`rejects a password over 1024 characters`) and Task 7 (`returns 422 for an empty username`).
5. **Choosing a hospital the user does not belong to**: must look like "not found", never reveal the hospital. Pinned in Task 6 (`selecting another user's membership is NOT_FOUND`).

```ts
import { z } from 'zod';

export const errorCodes = {
  UNAUTHENTICATED: 401,
  INVALID_CREDENTIALS: 401,
  PERMISSION_DENIED: 403,
  CSRF_TOKEN_INVALID: 403,
  TENANT_NOT_SELECTED: 403,
  MEMBERSHIP_NOT_ACTIVE: 403,
  NOT_FOUND: 404,
  VALIDATION_FAILED: 422,
  ACCOUNT_LOCKED: 423,
  INTERNAL_ERROR: 500,
  SERVICE_UNAVAILABLE: 503,
} as const;

export type ErrorCode = keyof typeof errorCodes;

export const problemSchema = z.object({
  type: z.string(),
  title: z.string(),
  status: z.number().int(),
  code: z.string(),
  detail: z.string().optional(),
  correlationId: z.string().optional(),
  fields: z.array(z.object({ path: z.string(), message: z.string() })).optional(),
});

export type Problem = z.infer<typeof problemSchema>;
```

```ts
// Time source injected into domain logic, so tests control "now" (session expiry, C-032).
export interface Clock {
  now(): Date;
}

export const systemClock: Clock = { now: () => new Date() };

export interface FixedClock extends Clock {
  advanceBy(milliseconds: number): void;
}

export function fixedClock(start: Date): FixedClock {
  let current = start.getTime();
  return {
    now: () => new Date(current),
    advanceBy: (milliseconds) => {
      current += milliseconds;
    },
  };
}
```

```ts
async function runInContext<T>(
  prisma: PrismaClient,
  tenantId: string,
  userId: string,
  fn: (tx: TenantTx) => Promise<T>,
): Promise<T> {
  return prisma.$transaction(
    async (tx) => {
      await tx.$executeRaw`SELECT set_config('app.tenant_id', ${tenantId}, true),
                                  set_config('app.user_id', ${userId}, true)`;
      return fn(tx);
    },
    // maxWait: how long to wait for a free pooled connection (Prisma's default is 2 s).
    // timeout: how long the transaction itself may run.
    { maxWait: 5_000, timeout: 5_000, isolationLevel: 'ReadCommitted' },
  );
}
```

```ts
// Converts every error into RFC 9457 problem+json with a stable code (D section 8.3).
// DomainErrors keep their code and details; Nest HTTP errors map by status; anything else is
// an unexpected INTERNAL_ERROR whose message is never sent to the client.
import { Catch, HttpException, type ArgumentsHost, type ExceptionFilter } from '@nestjs/common';
import { errorCodes, type ErrorCode } from '@hms/contracts';
import { DomainError } from '@hms/domain-kernel';

interface HttpResponseLike {
  status(code: number): HttpResponseLike;
  type(contentType: string): HttpResponseLike;
  send(body: string): void;
}

const statusToCode: Record<number, ErrorCode> = {
  401: 'UNAUTHENTICATED',
  403: 'PERMISSION_DENIED',
  404: 'NOT_FOUND',
  422: 'VALIDATION_FAILED',
  503: 'SERVICE_UNAVAILABLE',
};

function isKnownCode(code: string): code is ErrorCode {
  return Object.hasOwn(errorCodes, code);
}

@Catch()
export class ProblemDetailsFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost): void {
    const response = host.switchToHttp().getResponse<HttpResponseLike>();
    const problem = toProblem(exception);
    response.status(problem.status).type('application/problem+json').send(JSON.stringify(problem));
  }
}

function toProblem(exception: unknown): Record<string, unknown> & { status: number } {
  if (exception instanceof DomainError && isKnownCode(exception.code)) {
    const status = errorCodes[exception.code];
    return { ...base(exception.code, status, exception.message), ...exception.details };
  }
  if (exception instanceof HttpException) {
    const status = exception.getStatus();
    const code = statusToCode[status] ?? 'INTERNAL_ERROR';
    return base(code, status, exception.message);
  }
  return base('INTERNAL_ERROR', 500, 'Unexpected error');
}

function base(code: string, status: number, title: string) {
  return { type: `urn:hms:error:${code}`, title, status, code };
}
```

```ts
// Validates a request body with a contracts schema (ADR-005). Failures become
// VALIDATION_FAILED with one entry per field, so the UI can highlight inputs.
import type { PipeTransform } from '@nestjs/common';
import { DomainError } from '@hms/domain-kernel';
import type { z } from 'zod';

export class ZodBodyPipe<S extends z.ZodType> implements PipeTransform<unknown, z.infer<S>> {
  constructor(private readonly schema: S) {}

  transform(value: unknown): z.infer<S> {
    const result = this.schema.safeParse(value);
    if (result.success) return result.data;
    const fields = result.error.issues.map((issue) => ({
      path: issue.path.join('.'),
      message: issue.message,
    }));
    throw new DomainError('VALIDATION_FAILED', 'Request body is invalid', { fields });
  }
}
```

```ts
// Session timing rules (C-032: 60 minutes idle, 12 hours absolute; FR-ACC-003, FR-ACC-005).
// Pure functions: the caller passes "now", so tests control time.

export interface SessionTimeouts {
  idleMinutes: number;
  absoluteHours: number;
}

export interface SessionTimes {
  idleExpiresAt: Date;
  absoluteExpiresAt: Date;
}

const MINUTE = 60_000;
const HOUR = 60 * MINUTE;
// Writing last_seen_at on every request would turn reads into writes; once a minute is enough
// for a 60-minute idle timeout.
const TOUCH_INTERVAL = MINUTE;

export function newSessionTimes(now: Date, timeouts: SessionTimeouts): SessionTimes {
  return {
    idleExpiresAt: new Date(now.getTime() + timeouts.idleMinutes * MINUTE),
    absoluteExpiresAt: new Date(now.getTime() + timeouts.absoluteHours * HOUR),
  };
}

export function isSessionExpired(
  session: SessionTimes & { revokedAt: Date | null },
  now: Date,
): boolean {
  return (
    session.revokedAt !== null ||
    now.getTime() >= session.idleExpiresAt.getTime() ||
    now.getTime() >= session.absoluteExpiresAt.getTime()
  );
}

/** New idle expiry after activity; never later than the absolute expiry. */
export function slideIdleExpiry(session: SessionTimes, now: Date, timeouts: SessionTimeouts): Date {
  const slid = now.getTime() + timeouts.idleMinutes * MINUTE;
  return new Date(Math.min(slid, session.absoluteExpiresAt.getTime()));
}

export function shouldTouch(lastSeenAt: Date, now: Date): boolean {
  return now.getTime() - lastSeenAt.getTime() > TOUCH_INTERVAL;
}
```

```ts
  return raw.normalize('NFKC').trim().toLowerCase();
}

export function assertAccountCanLogin(
  account: { status: AccountStatus; lockedUntil: Date | null },
  now: Date,
): void {
  switch (account.status) {
    case 'ACTIVE':
      return;
    case 'LOCKED_TEMPORARY':
      if (account.lockedUntil !== null && account.lockedUntil.getTime() > now.getTime()) {
        throw new DomainError('ACCOUNT_LOCKED', 'Account is locked', {
          lockedUntil: account.lockedUntil.toISOString(),
        });
      }
      return;
    case 'LOCKED_ADMIN':
      throw new DomainError('ACCOUNT_LOCKED', 'Account is locked by an administrator');
    case 'DISABLED':
      // Same answer as a wrong password, so a disabled account cannot be told apart.
      throw new DomainError('INVALID_CREDENTIALS', 'Invalid username or password');
  }
}
```

```ts
// argon2id password hashing (ADR-004). Parameters follow the OWASP minimum for argon2id
// (19 MiB memory, 2 iterations, 1 lane), which keeps a login near 50 ms on the 2 vCPU server.
import argon2 from 'argon2';

const OPTIONS = { type: argon2.argon2id, memoryCost: 19_456, timeCost: 2, parallelism: 1 } as const;

let dummyHash: Promise<string> | undefined;

export function hashPassword(plain: string): Promise<string> {
  return argon2.hash(plain, OPTIONS);
}
```

```ts
// CSRF token bound to the session: HMAC-SHA256(secret, session token) (decision 2 of the
// T-ACC-01 plan, ADR-021). Mandatory because every *.bytespate.com site is "same-site".
import { createHmac, timingSafeEqual } from 'node:crypto';

export function csrfTokenFor(sessionToken: string, secret: string): string {
  return createHmac('sha256', secret).update(sessionToken).digest('base64url');
}

export function isValidCsrfToken(sessionToken: string, candidate: string, secret: string): boolean {
  const expected = Buffer.from(csrfTokenFor(sessionToken, secret));
  const actual = Buffer.from(candidate);
  // timingSafeEqual needs equal lengths; a length mismatch is simply invalid.
  return expected.length === actual.length && timingSafeEqual(expected, actual);
}
```

```ts
const INVALID = 'Invalid username or password';

@Injectable()
export class AuthService {
  constructor(
    @Inject(PRISMA) private readonly prisma: PrismaClient,
    @Inject(AUTH_CONFIG) private readonly config: AuthConfig,
    @Inject(CLOCK) private readonly clock: Clock,
  ) {}

  async login(input: LoginRequest, meta: RequestMeta): Promise<IssuedSession> {
    const username = normalizeUsername(input.username);
    const user = await findUserByUsername(this.prisma, username);
    if (!user) {
      await verifyAgainstDummy(input.password);
      await this.authEvent('auth.login.failed', 'FAILED', meta, {
        usernameAttempted: username,
        reason: 'UNKNOWN_USER',
      });
      throw new DomainError('INVALID_CREDENTIALS', INVALID);
    }

    const now = this.clock.now();
    try {
      assertAccountCanLogin(user, now);
    } catch (error) {
      await this.authEvent('auth.login.failed', 'DENIED', meta, {
        userId: user.id,
        reason: (error as DomainError).code,
      });
      throw error;
    }

    if (!(await verifyPassword(user.passwordHash, input.password))) {
      await recordFailedLogin(this.prisma, user.id);
      await this.authEvent('auth.login.failed', 'FAILED', meta, {
        userId: user.id,
        reason: 'BAD_PASSWORD',
      });
      throw new DomainError('INVALID_CREDENTIALS', INVALID);
    }

    const memberships = await this.activeMemberships(user.id);
    if (memberships.length === 0) {
      await this.authEvent('auth.login.failed', 'DENIED', meta, {
        userId: user.id,
        reason: 'NO_ACTIVE_MEMBERSHIP',
      });
      throw new DomainError('MEMBERSHIP_NOT_ACTIVE', 'Access to this hospital is not active');
    }

    await resetFailedLogins(this.prisma, user.id);
    // FR-ACC-002: with exactly one hospital the choice is automatic (UC-ACC-01 A1).
    const bound = memberships.length === 1 ? memberships[0]! : null;
    const issued = await this.startSession(user, memberships, bound, meta);
    await this.authEvent('auth.login.succeeded', 'SUCCEEDED', meta, { userId: user.id });
    return issued;
  }

  async selectMembership(
    ctx: AuthContext,
    membershipId: string,
    meta: RequestMeta,
  ): Promise<IssuedSession> {
    const user = await this.requireUser(ctx.userId);
    const memberships = await this.activeMemberships(user.id);
    const chosen = memberships.find((m) => m.id === membershipId);
    // Another user's or an inactive membership looks the same as a missing one (D section 8.3).
    if (!chosen) throw new DomainError('NOT_FOUND', 'Membership not found');

    // ADR-004: a new session ID on hospital switch; the old token stops working at once.
    await revokeSession(this.prisma, ctx.tokenHash, this.clock.now());
    return this.startSession(user, memberships, chosen, meta);
  }

  async resolveSession(token: string): Promise<AuthContext | null> {
    const tokenHash = hashSessionToken(token);
    const session = await findSessionByTokenHash(this.prisma, tokenHash);
    const now = this.clock.now();
    if (!session || isSessionExpired(session, now)) return null;

    if (shouldTouch(session.lastSeenAt, now)) {
      await touchSession(
        this.prisma,
        tokenHash,
        now,
        slideIdleExpiry(session, now, this.config.timeouts),
      );
    }
    return {
      userId: session.userId,
      tenantId: session.tenantId,
      membershipId: session.membershipId,
      tokenHash,
    };
  }

  async describeSession(ctx: AuthContext, token: string): Promise<SessionResponse> {
    const user = await this.requireUser(ctx.userId);
    const session = await findSessionByTokenHash(this.prisma, ctx.tokenHash);
    if (!session) throw new DomainError('UNAUTHENTICATED', 'Session ended');
    return this.toResponse(
      user,
      await this.activeMemberships(user.id),
      ctx.membershipId,
      token,
      session,
    );
  }

  async logout(ctx: AuthContext, meta: RequestMeta): Promise<void> {
    await revokeSession(this.prisma, ctx.tokenHash, this.clock.now());
    if (ctx.tenantId && ctx.membershipId) {
      await this.tenantAudit(ctx.tenantId, ctx.userId, ctx.membershipId, 'auth.logout', meta);
    }
    await this.authEvent('auth.logout', 'SUCCEEDED', meta, { userId: ctx.userId });
  }

  private async startSession(
    user: UserRecord,
    memberships: MembershipRecord[],
    bound: MembershipRecord | null,
    meta: RequestMeta,
  ): Promise<IssuedSession> {
    const token = newSessionToken();
    const now = this.clock.now();
    const times = newSessionTimes(now, this.config.timeouts);
    await insertSession(this.prisma, {
      tokenHash: hashSessionToken(token),
      userId: user.id,
      tenantId: bound?.tenantId ?? null,
      membershipId: bound?.id ?? null,
      createdAt: now,
      ...times,
    });
    if (bound)
      await this.tenantAudit(bound.tenantId, user.id, bound.id, 'auth.login.succeeded', meta);
    return { token, session: this.toResponse(user, memberships, bound?.id ?? null, token, times) };
  }

  private toResponse(
    user: UserRecord,
    memberships: MembershipRecord[],
    activeMembershipId: string | null,
    token: string,
    times: { idleExpiresAt: Date; absoluteExpiresAt: Date },
  ): SessionResponse {
    return {
      user: {
        id: user.id,
        displayName: user.displayName,
        preferredLang: user.preferredLang === 'bn_BD' ? 'bn-BD' : 'en',
      },
      memberships: memberships.map(toSummary),
      activeMembershipId,
      csrfToken: csrfTokenFor(token, this.config.csrfSecret),
      idleExpiresAt: times.idleExpiresAt.toISOString(),
      absoluteExpiresAt: times.absoluteExpiresAt.toISOString(),
    };
  }

  private async activeMemberships(userId: string): Promise<MembershipRecord[]> {
    const all = await listMembershipsForUser(this.prisma, userId);
    return all.filter((m) => m.status === 'ACTIVE');
  }

  private async requireUser(userId: string): Promise<UserRecord> {
    const user = await findUserById(this.prisma, userId);
    if (!user) throw new DomainError('UNAUTHENTICATED', 'Session ended');
    return user;
  }

  private tenantAudit(
    tenantId: string,
    userId: string,
    membershipId: string,
    action: string,
    meta: RequestMeta,
  ) {
    return withTenant(this.prisma, { tenantId, userId }, (tx) =>
      appendAuditEvent(tx, {
        tenantId,
        action,
        outcome: 'SUCCEEDED',
        actorUserId: userId,
        membershipId,
        ...(meta.correlationId ? { correlationId: meta.correlationId } : {}),
      }),
    );
  }

  private authEvent(
    action: string,
    outcome: 'SUCCEEDED' | 'DENIED' | 'FAILED',
    meta: RequestMeta,
    extra: { userId?: string; usernameAttempted?: string; reason?: string },
  ): Promise<void> {
    return appendAuthEvent(this.prisma, { action, outcome, ...meta, ...extra });
  }
}

function toSummary(m: MembershipRecord): MembershipSummary {
  return {
    id: m.id,
    tenantId: m.tenantId,
    tenantNameEn: m.tenantNameEn,
    tenantNameBn: m.tenantNameBn,
  };
}
```

```ts
// Global guards, in order: who is calling (session), is the write intended (CSRF + Origin),
// and is a hospital chosen (tenant). FR-ACC-001, FR-ACC-002, FR-ACC-009, ADR-021.
import { Inject, Injectable, type CanActivate, type ExecutionContext } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { DomainError } from '@hms/domain-kernel';
import { AUTH_CONFIG, type AuthConfig } from '../application/auth.config.js';
import { AuthService } from '../application/auth.service.js';
import { isValidCsrfToken } from '../infrastructure/csrf-token.js';
import { ALLOW_WITHOUT_TENANT_KEY, PUBLIC_KEY } from './decorators.js';
import type { AuthenticatedRequest } from './request-context.js';
import { SESSION_COOKIE } from './session-cookie.js';

const SAFE_METHODS = new Set(['GET', 'HEAD', 'OPTIONS']);
export const ALLOWED_ORIGINS = Symbol('ALLOWED_ORIGINS');

function flag(reflector: Reflector, key: string, context: ExecutionContext): boolean {
  return (
    reflector.getAllAndOverride<boolean>(key, [context.getHandler(), context.getClass()]) === true
  );
}

@Injectable()
export class SessionGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    private readonly auth: AuthService,
  ) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    if (flag(this.reflector, PUBLIC_KEY, context)) return true;
    const request = context.switchToHttp().getRequest<AuthenticatedRequest>();
    const token: unknown = request.cookies?.[SESSION_COOKIE];
    const ctx =
      typeof token === 'string' && token.length > 0 ? await this.auth.resolveSession(token) : null;
    if (!ctx) throw new DomainError('UNAUTHENTICATED', 'Login required');
    request.auth = ctx;
    request.sessionToken = token as string;
    return true;
  }
}

@Injectable()
export class CsrfGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    @Inject(AUTH_CONFIG) private readonly config: AuthConfig,
    @Inject(ALLOWED_ORIGINS) private readonly allowedOrigins: ReadonlySet<string>,
  ) {}

  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest<AuthenticatedRequest>();
    if (flag(this.reflector, PUBLIC_KEY, context) || SAFE_METHODS.has(request.method)) return true;
    // Browsers always send Origin on cross-origin writes; a foreign origin is refused even
    // with a valid token. Non-browser clients without Origin still need the token.
    const origin = request.headers.origin;
    if (origin !== undefined && !this.allowedOrigins.has(origin)) {
      throw new DomainError('CSRF_TOKEN_INVALID', 'Request origin is not allowed');
    }
    const candidate = request.headers['x-csrf-token'];
    const valid =
      typeof candidate === 'string' &&
      request.sessionToken !== undefined &&
      isValidCsrfToken(request.sessionToken, candidate, this.config.csrfSecret);
    if (!valid) throw new DomainError('CSRF_TOKEN_INVALID', 'CSRF token missing or invalid');
    return true;
  }
}

@Injectable()
export class TenantGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    if (
      flag(this.reflector, PUBLIC_KEY, context) ||
      flag(this.reflector, ALLOW_WITHOUT_TENANT_KEY, context)
    ) {
      return true;
    }
    const request = context.switchToHttp().getRequest<AuthenticatedRequest>();
    if (!request.auth?.tenantId)
      throw new DomainError('TENANT_NOT_SELECTED', 'Choose a hospital first');
    return true;
  }
}
```

```ts
  @HttpCode(200)
  async login(
    @Body(new ZodBodyPipe(loginRequestSchema)) body: LoginRequest,
    @Req() request: AuthenticatedRequest,
    @Res({ passthrough: true }) response: Response,
  ): Promise<SessionResponse> {
    return this.issue(response, await this.auth.login(body, metaOf(request)));
  }

  @AllowWithoutTenant()
  @Get('session')
  session(@Req() request: AuthenticatedRequest): Promise<SessionResponse> {
    return this.auth.describeSession(getAuthContext(request), request.sessionToken!);
  }

  @AllowWithoutTenant()
  @Post('session/membership')
  @HttpCode(200)
  async selectMembership(
    @Body(new ZodBodyPipe(selectMembershipRequestSchema)) body: SelectMembershipRequest,
    @Req() request: AuthenticatedRequest,
    @Res({ passthrough: true }) response: Response,
  ): Promise<SessionResponse> {
    const issued = await this.auth.selectMembership(
      getAuthContext(request),
      body.membershipId,
      metaOf(request),
    );
    return this.issue(response, issued);
  }

  @AllowWithoutTenant()
  @Post('logout')
  @HttpCode(204)
  async logout(
    @Req() request: AuthenticatedRequest,
    @Res({ passthrough: true }) response: Response,
  ): Promise<void> {
    await this.auth.logout(getAuthContext(request), metaOf(request));
    response.clearCookie(SESSION_COOKIE, clearSessionCookieOptions);
  }

  private issue(response: Response, issued: IssuedSession): SessionResponse {
    const absolute = new Date(issued.session.absoluteExpiresAt);
    response.cookie(SESSION_COOKIE, issued.token, sessionCookieOptions(absolute, new Date()));
    return issued.session;
  }
}
```

```ts
  /** Exact web origins allowed to send writes (same list as CORS_ORIGINS). */
  allowedOrigins?: readonly string[];
}

@Module({})
export class IdentityAccessModule {
  static forRoot(
    config: AuthConfig,
    clock: Clock = systemClock,
    options: IdentityAccessOptions = {},
  ): DynamicModule {
    return {
      module: IdentityAccessModule,
      controllers: [AuthController],
      providers: [
        AuthService,
        { provide: AUTH_CONFIG, useValue: config },

      exports: [AuthService],
```

```ts
// CORS allow-list for the separate web origin (ADR-021). Only exact origins get CORS headers;
// credentials (the session cookie) are allowed for them.
import type { CorsOptions } from '@nestjs/common/interfaces/external/cors-options.interface.js';

export function parseCorsOrigins(value: string | undefined): string[] {
  if (!value) return [];
  return value
    .split(',')
    .map((origin) => origin.trim())
    .filter((origin) => origin.length > 0)
    .map((origin) => {
      if (new URL(origin).origin !== origin) {
        throw new Error(`CORS_ORIGINS entry must be a bare origin like https://host: ${origin}`);
      }
      return origin;
    });
}

export function buildCorsOptions(allowedOrigins: readonly string[]): CorsOptions {
  const allowed = new Set(allowedOrigins);
  return {
    // Requests without an Origin header (curl, health checks) are not CORS requests.
    origin: (origin, callback) => callback(null, origin === undefined || allowed.has(origin)),
    credentials: true,
    methods: ['GET', 'HEAD', 'POST', 'PUT', 'PATCH', 'DELETE'],
    allowedHeaders: ['Content-Type', 'X-CSRF-Token', 'Idempotency-Key', 'X-Request-Id'],
    maxAge: 7200,
  };
}
```

```ts
import type { NestExpressApplication } from '@nestjs/platform-express';
import { ProblemDetailsFilter } from '@hms/platform';
import cookieParser from 'cookie-parser';
import { buildCorsOptions, parseCorsOrigins } from './cors.js';

export function configureApp(app: NestExpressApplication, corsOrigins: string | undefined): void {
  // Only the host nginx reaches the container (ports bind to 127.0.0.1), via loopback or the
  // Docker bridge. Trusting those hops makes req.ip the real visitor IP for audit and lockout.
  app.set('trust proxy', 'loopback, uniquelocal');
```
